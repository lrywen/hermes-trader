## 1. 五段瀑布口径（严格加性，残差 = 0.000）

回测每笔成交口径（`scripts/bt_ra_exch.py:_emit`，L684-697）：

- `entry_px` 已含入场滑点；`exit_px = raw_px·(1 − sgn·exit_slip/1e4)`（权威 stop_delay=0）；
- `pnl_gross` 含双边滑点、不含手续费；`pnl_net = pnl_gross − notional·8.64bps`。

反解出严格加性瀑布：

```
S0 信号峰值毛利 = peak_pct（持仓期最大有利偏移，相对含滑点入场，零成本理想值）
L1 出场回吐     = raw 出场收益 − 峰值收益（DSL 跟踪回吐 / 止损触发，不含滑点费）
L2 出场滑点     = −exit_slip（per-coin 半价差）
L3 手续费       = −8.64 bps
净 = S0 + L1 + L2 + L3 = pnl_net/notional        （恒等，实测残差 0.000 bps）
```

> 口径注记：**入场滑点**已隐含在共同基准 `entry_px` 里（同时压低 peak 与 raw_ret，不进二者之差），
> 故不进净值恒等式，仅在末列名义列出（≈ −1.6~−2.0 bps，与出场滑点对称）。
> trade 记录未存「信号触发价（无滑点入场价）」，无法把入场滑点从 entry 基准分离进加性恒等；
> 这是当前字段的固有边界，不影响净额（pnl_net 是权威量）。

## 3. 结构性结论

1. **L1 出场回吐是绝对主因**：对齐实盘的 `filt` 臂，S0 峰值毛利 +88.5 bps 被 L1 回吐 −87.7 bps
   吃掉 **99%**；`filt_exch` 回吐 −90.7 bps（103%）。全臂 L1 占「毛利+各项损耗绝对量」的
   约 **88%**。手续费（8.64）+双边滑点（~3.6）合计仅约 12.2 bps，**不是**盈亏的决定项——
   决定项是 DSL 跟踪止损把浮盈几乎全额回吐。
2. 与计划基准方向一致（出场损耗是大头），但 81 币池 + per-coin 成本下回吐绝对量级比旧
   8 币 flat 口径（基准 −18.84 bps）更大——币池扩大后小币尾部回吐更重。
3. 两个对齐实盘出场占比的臂（B-3 结论：filt 52.5% floor / filt_exch 54.0% floor ≈ 实盘 52.6%）
   净期望都显著为负（−9.65 / −13.00 bps/笔）。

stop 类笔（floor_breach/exchange_trigger/max_loss）raw 出场收益（未扣滑点）分布：

|---|---:|---:|---:|---:|---:|---:|
| filt | 13982 | +0.8 | −100.0 | +27.3 | −171.5 | **0.8%** |
| filt_exch | 13983 | −2.6 | −100.0 | +27.9 | **−300.0** | **2.3%** |
| filt_ra | 12364 | −4.8 | −80.0 | −52.7 | −154.8 | 0.1% |

- p10 恰为 −100bps（filt/filt_exch），对应 1.00% regime cap 处集中触发（多数 stop 笔在 cap 位成交）；
- `filt_exch` 有 **2.3%** 的 stop 笔 raw 亏损 >1%、最深 **−3.00%**，即 B-1a-改② 的 PURR 级穿透 tail
  （−3.236% vs cap 1.67%）在 81 币池里由交易所镜像 Stop Market 建模复现；filt（无镜像）仅 0.8%、最深 −1.72%。
- 穿透是 L1 内部的 tail 贡献（非加性独立段，避免与 L1 重复计），量级集中在少数小币闪崩笔。
