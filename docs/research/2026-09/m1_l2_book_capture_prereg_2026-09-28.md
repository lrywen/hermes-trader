# M-1 L2 order book / CVD 微结构数据采集 + 30–60 天假设预注册

> 日期：2026-09-28
> 背景：连续四轮（趋势跟踪 / 埋伏 / 横截面反转 W-XSR1 / funding carry）在同一份 HL K线+funding 历史上失败（详见 w6、pa/pc/pd 关闭文件）。元结论：**问题在信息集而非指标选择**——K线+funding 是公开即时零门槛数据，edge 已被套利到基线。继续在该信息集上扫参/遗传算法=过拟合。
> 决策：用户选定「积累盘口/CVD 数据」，参数 Top 20 币 / 1 秒一快照 / 集成进现有容器。
> 本文件用途：**在看到任何微结构研究结果之前**固定假设、特征定义、标签、推断口径与判定阈值，杜绝看完数据再挑信号（HARKing）。

## 0. 采集器事实（已部署，2026-09-28）

- 代码：`hermes_trader/client/ws_client.py`（`start_book_capture` / `_on_book` / `_book_flush_loop`，含断线重订）；启动入口 `scripts/trading_loop.py`（读 `config["book_capture"]`，默认 enabled）。
- 落盘：`${HERMES_DATA_DIR:-/data}/book-raw/date=YYYY-MM-DD/COIN.jsonl`，UTC 分日，保留 14 天，由 `scripts/clean_trades_raw.py` 与 trades-raw 同一每日 job 清理。
- 行结构（每行一条 1s 快照）：
  ```json
  {"t": <flush wall ms>, "bt": <book event exchange ms>,
   "b": [["px","sz"], ... 10 档 bid],
   "a": [["px","sz"], ... 10 档 ask]}
  ```
- 币集：按 `dayNtlVlm` 排序的 Top 20 perp（含 BTC/ETH/SOL 等；剔除 `@` 现货）。币集随每日成交量自然轮换，分析时以「快照时点该币在榜」为准。
- 节奏：实测 BTC 3 秒 +3 行，严格 1s；10 档/侧。

> **数据局限（影响可检验的假设，必须先说清）**
> 1. 当前 book-raw **只存 1s 聚合快照，不存逐笔成交（tape）**。因此真正的成交驱动 CVD 在本数据里**不可直接计算**——本预注册主假设（H1 OFI）不依赖 tape；CVD 类假设（H3）标注为「需补 tape 或用快照 mid 变动代理」，不与主假设混为一谈。
> 2. 1s 粒度只能预测「秒级以上」的持续，无法检验做市级（<1s）信号。
> 3. Top 20 是高关注度币，微结构 edge 最可能已被吃掉；若这里无 edge，不代表小币无 edge（但小币不在本轮数据内，不据此扩展，避免看到结果后挪目标）。

## 1. 预注册主假设（唯一主假设，多重检验口径只对它负责）

### H1（primary）：订单流失衡 OFI 对短周期未来 mid 收益有正向样本外预测力

**方向（先固定）**：订单流净买入压力（OFI > 0）预测未来 mid **上涨**；OFI < 0 预测下跌。即信号与未来收益相关系数 > 0。

**特征定义（Cont 等 2014 口径，适配 1s 快照、best-10 档）**

逐快照对每币，基于前后两帧 best 档（必要时扩到前 k 档）计算 OFI。best-level 形式：

```
e_n = 1[Pn^b >= Pn-1^b] * Qn^b  - 1[Pn^b <= Pn-1^b] * Qn-1^b
      - 1[Pn^a <= Pn-1^a] * Qn^a  + 1[Pn^a >= Pn-1^a] * Qn-1^a
```

（P^b/P^a=best bid/ask，Q=对应挂量；价格不变时该项=本档挂量变化 ΔQ。）
深度扩展版 OFI-10：对 10 档分别按「同价位挂量变化 + 新价位进入/旧价位退出」求和，再用各档到 mid 的距离做固定权重衰减（权重 w_k = 1/k，**预先固定，不优化**）。

- 聚合窗口 W_OFI ∈ {**60s, 300s**}：把窗口内逐秒 e_n 求和，并用该窗口末档的 mid 价差或挂量做标准化（z = OFI / 窗口内 OFI 标准差，滚动只用过去数据）。**主口径固定 W_OFI=60s**；300s 仅作稳健性，不作为主结论。
- 不做参数搜索；阈值（如「OFI 极端分位才入场」）统一用**各币滚动过去 30 天的横截面+时序分位**，分位带 [0,10%) / (90%,100%] 预先固定。

**标签（label，先固定）**

- 主 horizon h = **5 分钟（300s）** 的 forward mid return：`y = (mid_{t+h} - mid_t)/mid_t`，mid=(best bid+best ask)/2。
- 次 horizon（稳健性，不决定主结论）：h ∈ {15m}。
- 标签用 mid 而非成交价，避免 bid-ask bounce 污染；同时单独报告「用 t 时刻 ask 买、t+h 时刻 bid 卖」的可执行口径（见成本）。

**入场→可执行收益（主检验用这个，而非裸相关）**

- 信号 z > +k（k 固定=对应过去30天 90 分位）→ 做多；z < −k → 做空；中间不交易。
- 持有 h=5m 后平仓，不提前止盈止损（检验的是「裸信号有没有毛 edge」）。
- 成本：每条腿 taker 费 + 开仓时 cross 半价差。回测口径采用 HL 真实 taker 费与该快照实测价差，**不假设 maker 成交**（P-B 已证明 maker 成交无法用历史验证）。

### H2（secondary，预注册但非主）：盘口失衡的「水平/斜率」预测变盘

- 特征：bid/ask 前 10 档**挂量的不对称**（bid 总量 − ask 总量，除以二者之和）、以及深度曲线斜率差。
- 假设：极端不对称 + 当前 mid 窄幅（低已实现波动）后，5/15m 收益朝堆积厚的一侧方向突破。
- 作为次要假设，显著性按 §3 多重检验校正后报告，**不能替代 H1 下结论**。

### H3（exploratory，明确标注，不计入「通过」计数）

- CVD / 价格背离、主动买卖压力。**当前数据无 tape，无法直接算 CVD**；仅在（a）后续补采逐笔成交，或（b）用「快照间 mid 变动 × 挂量变化」做近似代理时探索。
- 代理口径的结果一律标 exploratory，不作为策略上线依据。

## 2. 样本与时间切分（防止时间泄漏与重叠）

- **积累期**：采集从 2026-09-28 起；**至少满 30 个自然日才做首次分析，满 60 天做确认**。首次分析不早于 2026-10-28，确认不早于 2026-11-27。
- **train / test 时间切分（先固定）**：前 50% 天数仅用于确定标准化/分位的计算方式（不搜索参数）；后 50% 为**唯一报告检验结果的样本外区间**。指标定义本身不依赖 train 拟合，故 test 区间为真正 holdout。
- **去重叠**：5m 持有期内同一币不重复开新仓（信号每 5m 取一次，步进=持有期），杜绝同一行情被重复计数（W-XSR1 即因此假阳性）。

## 3. 推断口径与判定阈值（全部先固定）

- **推断单位**：以「快照时刻」聚类——同一时刻跨 20 币的信号高度相关，不能把跨币当独立。主推断用**按时间块的 block bootstrap**：块长 ≥ 2×h（5m 信号 → 块长取 15m，另报 1h 块稳健性），块内保留跨币相关结构。
- 对**每笔可执行净收益（已扣成本）序列**做 block bootstrap（B=10000，seed=20260928），报告均值 bps/笔的 95% CI。
- **通过判据（全部满足才算 H1 通过，任一不满足即关闭该方向）**：
  1. 样本外净 bps/笔的 95% block-bootstrap **CI 下界严格 > 0**；
  2. 方向与预注册一致（OFI+ → 收益+），不接受翻号；
  3. 主口径（W=60s, h=5m）单独成立——不允许用稳健性格子（300s/15m）里某个显著的来顶替；
  4. 多重检验：H1 为主假设不校正；H2 作为次要假设按 Holm（H1+H2 两个家族）校正后仍需 CI 下界>0。exploratory H3 不参与判定；
  5. 稳健性（不翻号即通过，不要求都显著）：换 1h 块、剔最高波动 10% 时段、只看 BTC/ETH 子集、剔单一最大贡献币——结论方向一致。
- **最小经济阈值（先固定，防止「统计显著但太薄」）**：样本外净均值 ≥ **3 bps/笔**（扣足 taker+价差后）。低于此值即便 CI>0 也判定为「不可交易」，不触发上线。
- 样本量：30 天 × 20 币 × (24h × 12 次/h) ≈ 17 万潜在信号点，去重叠+分位过滤后预计数千笔可执行交易；若样本外有效交易笔数 < 300，判定「样本不足」，延长采集而非降门槛。

## 4. 去拟合纪律（对照用户第 4 条要求）

- **不**在本数据上跑遗传算法/网格搜索去「最大化年化」。特征公式、窗口、horizon、分位阈值、块长、成本、经济阈值全部在看数前固定于本文件。
- 任何对参数的偏离都必须新开一个假设、用新的未使用数据段检验，不得回填到本轮结论。
- 主结论只承认一个预先指定的配置；稳健性格子只用于「会不会翻号」，不用于选最优。
- 不报告由 in-sample 优化得到的「年化收益」；只报告样本外、扣足成本、带 bootstrap CI 的 bps/笔与由交易频率推导的保守年化（且标注为情景而非承诺）。
