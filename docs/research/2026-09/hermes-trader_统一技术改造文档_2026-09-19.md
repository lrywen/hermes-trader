## §1 改造目标

### 1.1 总目标

> **在投入更多工程资源之前，用一套「能忠实评估实盘真实策略」的回测系统，判定这个策略是否真的存在可盈利边际（edge）；在判定完成前，不允许任何提高真实资金暴露的动作。**

### 1.2 三条主线

#### 主线 G1：建立可信的回测评估能力（**当前不存在**）

**问题**：现在的回测与实盘在**五个维度**上系统性不一致（币池 / 出场机制 / notional 规模 / 配置版本 / 杠杆依赖），导致回测数字**既不能证实也不能证伪**实盘。

**最直接的证据**：用真实的实盘配置（`filt_ra`）在回测里跑，`maxc=2` 时得到 **E1 −19.21% / E2 −3.88% / 夏普 −0.55**；而实盘 28 天真实成交是 **净 +8.25%**（但**不显著**，t=1.156）。两者差距无法归因。

**目标**：让回测在**出场机制**与**杠杆依赖**两个最关键维度上与实盘等价，使回测结论可以外推到实盘。

**验收**：§5.1 判据 1–5 全部通过。

---

#### 主线 G2：定位并拆除结构性损耗

**问题**：P5-1 完成了本项目**唯一一次完整的损耗分解**：

```
零成本毛利                        +29.22 bps   (t=3.15，块自助 [+1.10, +56.40] 不含 0)
  − 出场引擎代价（DSL vs 纯时间）  −18.84 bps   ← 最大单一损耗，占毛利的 64%
  − 真实交易成本                   − 9.26 bps
  ─────────────────────────────────────────
  = 净期望                         + 1.1 bps   ← 事实上归零
```

**目标**：把 −18.84 bps 的出场引擎代价**分解到可归因的机制**上，判断哪些是设计缺陷、哪些是必要成本。

**已知线索**：
- 止损反直觉证据：`max_loss` 138 笔实盘 **−108.95** vs 不止损持有到 240m **−81.25** → **止损多亏 27.70 bps**
- `stale_flat_timeout` 配对差 **−0.00**（62 笔完全一致）→ 这条路径**零代价**，是干净的
- 交易所侧追踪止损（Stop Market）在 347 条订单里被 **cancel + replace 平均 8 次/笔持仓**

**验收**：能给出「−18.84 bps 中，X bps 来自止损过紧、Y bps 来自追踪缓冲、Z bps 来自超时」的量化归因。

---

#### 主线 G3：在 edge 确认前冻结资金暴露

**当前风险状态（🔴 高危）**：

```
HERMES_ENABLE_LIVE = true      ← 环境变量已授权真实下单
mode               = SHADOW    ← 但模式仍是影子
```

**只差一个字符串就会下真单**。而回测显示，这个配置（`filt_ra`）在 `maxc=2` 下**亏 −19.21%**。

**目标**：建立**配置冻结机制 + 变更门槛**，使「把 `mode` 从 `SHADOW` 改成 `LIVE`」这个动作必须通过明确的验收门（§5.2）。

**现状**：`0.4_ADR-001` 已定义三条不变量，但**没有强制机制**（无 CI 检查、无启动断言）。

---

### 1.3 明确的非目标（**不要做**）

| 非目标 | 原因 |
|---|---|
| 现在就去调参提高收益 | 样本量不足（见下），调参 = 过拟合 |
| 现在就去实现 P3-3 的 gate | P3-4 已判定 **不能上线**（稳健性全败） |
| 现在就去加资金 | 资金不是瓶颈（$30.58 下利用率仅 8.4%，但**先确认 edge 再加钱**） |
| 现在就修 `events.jsonl` | 它是**合成数据**（P5-1 五条证据），修它没意义，应弃用 |
| 迁移到更高周期（1h） | **暂缓** —— 虽然 P1 显示 1h 往返成本占比从 195% 降到 61%，但在 G1 完成前迁移会引入新变量 |

### 1.4 最硬的约束：样本量

**这是全部改造都无法绕开的物理上限**：

| 指标 | 数值 |
|---|---|
| 实盘运行时长 | 28 天 |
| 实盘平仓笔数 | 36 笔（70 笔成交） |
| 实盘有效交易日 | **仅 11 天** |
| HL 5m K 线可用历史 | **17.4 天**（5,016 根，硬性滚动窗口） |
| HL 原生回测最大样本 | **73 笔** |
| HL 原生回测可检出最小效应 | **45.5 bps** |
| 要检出 +10 bps 改进所需笔数 | **1,161 笔** |
| 按线上 2 笔/天折算 | **约 19 个月** |

**结论**：在当前数据下，**任何小于 45 bps 的效应都无法被检出**。策略的真实 alpha（+24.17 bps）**低于可检出阈值**。

因此存在两条互斥的路径（Sprint0 原始结论，仍然有效）：

- **路径 A（推荐）**：以**回测为主要判据**。前提是 G1 完成（回测可信）。用 8 币 × 180 天的 5m/1h 数据 + Binance 代理（价格相关 0.9998+）扩充样本。
- **路径 B**：**注资到 $1k–5k**，把实盘成交速度提到能积累样本的量级。

> ⚠️ 路径 A 的前提是**回测可信**。目前不满足 → **所以 G1 是第一优先**。
