# M-5 预注册：动量信号执行层 SHADOW A/B — 立即 taker vs 回调限价

- 预注册日期：2026-09-30（Asia/Shanghai）
- 作者：量化研究（看结果前冻结）
- 触发：用户要求检验"信号触发后不立刻市价追入、改为小幅回调限价入场"能否减损。
- 性质：**执行层（execution）减损检验**。不预测方向、不判断动量阶段，零新增拟合自由度
  （唯一变量是下单方式）。结论为通用执行结论，可迁移回 HL。

---

## §0 为什么用 Binance 逐笔而非 HL 信号

- 限价回调能否成交取决于**价格路径**（是否先回撤到限价）。
- HL shadow 只存成交价、HL 免费 K线 count 上限约2000（1m 仅覆盖~33h），**无法对历史信号做
  intrabar 成交判定**；用收盘价近似会系统性高估成交率。
- 故采用 `/mnt/tick` BTC/ETH **逐笔**（270天、精确路径、含买卖方向），在其上重建一个与生产
  动量触发**同口径核心**的信号，比较两种执行。检验对象是"执行方法"，跨所迁移成立。

## §1 信号重建（固定，阈值仅训练段估）

逐笔聚合 5m bar（OHLCV + taker buy quote）。信号在 bar 收盘 t0 判定：

```
long  if  ret5 = (close/open - 1) ≥ k_ret   AND   vol5 ≥ k_vol · SMA20(vol5)
short if  ret5 ≤ −k_ret                      AND   vol5 ≥ k_vol · SMA20(vol5)
```

- `k_ret`、`k_vol` 只从训练段取：k_ret = 训练段 |ret5| 的 90% 分位；k_vol 固定 **1.5**（不估计）。
- 去重叠：信号仅在持仓空闲时生效；同方向连续 bar 只取第一根。

## §2 两种执行（同一信号、同一持有期）

- t0 = 信号 bar 收盘时间；P0 = 信号 bar 收盘价。
- **A / taker（现状）**：t0 后第一笔成交价立即吃单。
- **B / post-only 限价回调**：
  - 挂单价 long: `P0·(1−r)`；short: `P0·(1+r)`，固定 **r = 0.10%**（10bps）。
  - 用 t0 后逐笔判定：long 当某笔成交价 ≤ 挂单价 → 成交；short ≥ 挂单价 → 成交。
  - 超时 **W = 15m** 未成交 → 取消，记为"未成交（踏空）"，**不追价、不计盈亏**。
- 成交后统一持有 **H = 15m**，以 H 时刻后第一笔成交价平仓（taker 平仓）。

## §3 成本口径（保守）

- A：taker 进出 = 往返 **9 bps** 费。
- B：入场 post-only **maker 2 bps**，平仓 taker 4.5bps → 往返 **6.5 bps**；
  不假设 B 平仓也能 maker。
- 成交价用真实逐笔价，不再另加滑点（逐笔即真实）。

## §4 样本与切分

- 币种：BTCUSDT、ETHUSDT；窗口 **2026-01-01 → 2026-09-27（270天）**。
- 切分点 = **2026-03-31**：训练段（估 k_ret）< 切分；**测试段唯一报告** ≥ 切分。

## §5 推断与门槛

### 5.1 block-bootstrap
按天块（1自然日）对测试段重采样 2000 次，种子 20260930；
分别对 **A 净bps序列**、**B 已成交净bps序列**、以及**口径 B'（未成交按0计入，反映真实总损益）**
计算均值 95% CI。

### 5.2 主裁决（执行层是否改限价）
1. **B' 净均值 ≥ A 净均值**，且二者差 Δ(B′−A) 的按天块 CI 下界 **≥ 0**（不要求>0，减损可以为持平）；
2. B 成交率 **≥ 50%**（否则策略实际被掏空，靠系统性踏空"美化"）；
3. 报告 B 已成交口径的均值（说明选中的单质量）与踏空单事后若 taker 入场本可获得的收益
   （机会成本，必须非显著为正否则限价在"躲亏损"也在"躲盈利"）；
4. 有效 A 交易 ≥ 300。

> 诚实预期：这是减损检验。即使 PASS，也不代表系统转正；A 在 M-2 口径已≈−11bp。
> 若 B 与 A 无差异或成交率过低 → 执行层不改。

## §6 已知限制

1. 信号为 Binance 重建的动量核心，非 HL 复合打分全量；迁移回 HL 后真实成交率需再 shadow 确认。
2. 逐笔成交判定为"价格触及即成交"，未模拟队列位置（限价单可能未排到）→ **高估** B 成交率，
   方向上对 B 偏乐观，结论若 B 不佳则更可信。
3. r/W/H 三参数冻结，不做扫描；改值即另开假设。
