### A. 系统侧（代码 / 运维，3 项）

#### A-1 ⚠️ 降权改造上线时发生过一次真实崩溃（已修复）

| 项 | 内容 |
|---|---|
| **现象** | 首次降权上线后，降权用户（uid 1000）在 import 阶段崩溃 |
| **根因** | `setpriv` 保留了继承的 `HOME=/root`，而 `/root` 权限 0700，uid 1000 **无法穿越**，导致访问 `~/.hermes/universe_cache` 与 `~/.hermes` 锁文件失败 |
| **证据** | `Dockerfile` 内留存的修复注释："**P1-5 fix (2026-09-17): setpriv keeps the inherited HOME=/root, so the dropped user (uid 1000) could not traverse /root (0700) and crashed at import on ~/.hermes/universe_cache and ~/.hermes locks.**" |
| **修复** | `ENV HOME=/home/hermes`；只读共享配置改挂载到 `/home/hermes/.hermes-trading` |
| **状态** | ✅ 已修复并验证（运行容器进程实测全部为 `hermes` 用户，healthy，0 restart） |
| **教训** | 运维类改造本身有真实风险，需配套"上线后验证"而非"写完即认为完成" |
