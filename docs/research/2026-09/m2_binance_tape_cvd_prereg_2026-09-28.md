# M-2 Binance 逐笔 tape（CVD / 主动净流）历史回放预注册

> 日期：2026-09-28
> 背景：M-1 的 HL book-raw 只存 1s 快照、不含逐笔 tape，真正的成交 CVD 无法计算，且要等 30–60 天。用户提出换交易所走历史数据。核查发现本机 `/mnt/tick/raw/parquet` 存有 **Binance U本位永续逐笔成交**，已从原始 223 天补齐为 **270 个连续交易日（2026-01-01 → 2026-09-27）**，含 `is_buyer_maker`，可直接、免费计算真 CVD。
> 本文件用途：**在跑出任何信号结果之前**固定信号、标签、成本、时间切分与判定阈值，杜绝看完数据挑信号（HARKing）。本回放是一次性、严格样本外检验；**不跑遗传算法 / 网格扫参**。

---

## 0. 数据事实（已校验，2026-09-28）

- 路径：`/mnt/tick/raw/parquet/{BTCUSDT,ETHUSDT}/{SYMBOL}-trades-YYYY-MM-DD.parquet`
- 覆盖：每币 **270 个 parquet，2026-01-01 → 2026-09-27，日期零缺口**；每文件时间均落在当日 UTC。
- schema（6 列，已逐文件抽查一致）：
  `trade_id:int64, price:float64, qty:float64, quote_qty:float64, time:int64(ms), is_buyer_maker:bool`
- 含义：`is_buyer_maker=True` 表示该笔由挂单方（maker）是买方，即**主动卖单（s 方向）**；`False` 为**主动买单（b 方向）**。

> **数据局限（影响可检验假设，必须先说清）**
> 1. 只有 **BTC、ETH** 两个全球最深、最受关注的币；tape 是公开历史，CVD 类公开信号**大概率已被套利**。本检验大概率被证伪，但成本极低、值得一次性严格判。
> 2. 只有成交、**无 L2 档位**，算不了 OFI / 盘口深度（那走 M-1 的 HL book-raw）。
> 3. 逐笔无报价，无法直接知道每时刻真实 spread；可执行口径用**保守固定成本 + 成交冲击代理**（见 §3），不靠乐观的「贴中间价成交」。
> 4. 即便在 Binance 上成立，迁回 Hyperliquid 需另开假设、在 HL 补采 perp trade tape 后重新检验，**不得**直接把 Binance 结论当 HL 上线依据。

## 1. 预注册主假设（唯一主假设）

### H1（primary）：短窗 CVD 极端净流对未来短期收益有方向一致的样本外预测力

**方向（先固定）**：窗口内主动净买入（signed flow 为正）且达到极端分位 → 未来短期 mid **上涨**（做多）；主动净卖出极端 → 下跌（做空）。信号与未来收益符号一致。

**CVD / signed flow 定义（先固定）**

逐笔带符号成交额：

```
s_i = +quote_qty_i        if is_buyer_maker == False   # 主动买
      -quote_qty_i        if is_buyer_maker == True    # 主动卖
```

- 用 **quote_qty（名义 USDT）** 累加，消除两币价格量纲差异。
- 窗口 CVD：`CVD_W(t) = Σ_{i: t-W < time_i ≤ t} s_i`
- 标准化（只用过去，防泄漏）：`z(t) = CVD_W(t) / std(CVD_W over trailing lookback L)`，其中滚动标准差仅用 t 之前的窗口值。
- **主口径固定 W = 60s，L = 过去 24h 的 5m 网格点（288 点）**。不搜索窗口。
- **入场阈值（先固定）**：以**各币、过去 30 个自然日**的同网格 z 值分布取经验分位，`z ≥ q90` 做多、`z ≤ q10` 做空，中间不交易。q10/q90 仅用入场时点之前的数据计算。

**标签（label，先固定）**

- 主 horizon h = **5 分钟**：`y = (P_{t+h} − P_t)/P_t`，P 用该网格时刻**最近一笔成交价**（tape 数据无 mid；同时单独报告加了固定半价差的可执行口径，见 §3）。
- 次 horizon（稳健性，不决定主结论）：h = 15m。

### H2（secondary，预注册但非主）：CVD–价格背离

- 定义：过去 R=15m 内价格变动方向与累计 CVD 方向**相反**（价涨 + CVD 净流出，或反之）。
- 假设：背离后短期出现朝 CVD 方向的回归（资金流领先价格）。
- 显著性按 §3 多重检验校正后报告，**不能替代 H1 下结论**。

> H3（exploratory，不参与判定）：成交冲击自相关、大小单分层、更长 horizon 等，一律标 exploratory。

## 2. 样本与时间切分（防泄漏 / 防重叠）

- **网格**：统一对齐 **5 分钟 UTC 网格**（00:00, 00:05, …），信号在每根网格闭合时计算；h=5m 时持有到下一根网格，**步进 = 持有期，去重叠**，杜绝 W-XSR1 那种同一行情重复计数。
- **train / test 时间切分（先固定，按天）**：
  - 270 天按日历顺序，**前 50% 天（2026-01-01 → 约 2026-05-15）为 train**，仅用于确认标准化/分位计算方式（不搜索参数）；
  - **后 50% 天（约 2026-05-16 → 2026-09-27）为唯一报告的样本外区间（test）**。
  - 分位与滚动 std 在 test 内仍用「各自时点之前 30 天/24h」的滚动数据（可含 train），属因果可得，不构成未来泄漏。
- 分位 warm-up：每币滚动 30 天分位需要前置数据；test 起点附近不足 30 天的网格点记 warm-up 剔除。

## 3. 成本、推断与判定阈值（全部先固定）

**成本（保守、固定，不靠看数）**

- 单笔开+平的可执行净收益：
  `net = side * gross − COST_RT`
- `COST_RT`（round-trip，按名义额的比例）固定 = **taker 手续费 2×0.00045（开/平各 4.5bp，共 9bp）+ 2×半价差（共 1 个 spread）**。
- Binance U本位永续标准 taker 费 = 0.0500%（5bp/腿）。BTC/ETH 在正常时段账面 spread 通常约 1bp，但为覆盖极端波动与滑点，**spread 口径保守固定为 2bp**。
- 故主口径 **COST_RT = 9bp + 2bp = 11bp（0.0011）**。
  - 同时报告 **COST_RT = 9bp（仅手续费，最乐观）** 与 **COST_RT = 15bp（更保守）** 两档敏感性；**主判定只对 11bp 口径负责**。
- 不假设 maker 成交。

**推断单位 / bootstrap**

- 信号在同一时刻跨 BTC、ETH 相关，**不能把跨币当独立**。主推断把每笔净收益按其入场时间归入 **1 天块（UTC）**，块内保留跨币结构，对「按天平均净 bps」序列做**移动块 block bootstrap**（块长 = 5 天，B=10000，seed=20260928），报告均值 bps/笔的 95% CI。
- 复用 `hermes_trader/validation/significance.py`（如需 5 天移动块的重采样在脚本内实现并注明，不改动共享函数的既有口径）。

**通过判据（H1 全部满足才算通过，任一不满足即关闭该方向）**

1. 样本外（test）净 bps/笔的 95% block-bootstrap **CI 下界严格 > 0**（主口径 COST_RT=11bp）；
2. 方向与预注册一致（净流+ → 收益+），不接受翻号；
3. 主口径（W=60s, h=5m）单独成立——不允许用 15m / H2 / 其它成本档里某个显著的顶替；
4. 多重检验：H1 为主不校正；H2 次要，按 Holm（H1+H2 家族）校正后仍需 CI 下界>0；exploratory 不参与；
5. 最小经济阈值：test **净均值 ≥ 3 bps/笔**（11bp 成本后）。低于此即便 CI>0 也判「统计显著但不可交易」；
6. 样本量：test 有效交易笔数若 < 300，判「样本不足」而非降门槛；
7. 稳健性（不翻号即过，不要求都显著）：15m horizon、9bp/15bp 成本档、1 天与 10 天 bootstrap 块、剔 BTC 单币 / 剔 ETH 单币、剔波动最高 10% 的天——方向一致。

## 4. 去拟合纪律

- 不跑遗传算法 / 网格 / 贝叶斯扫参；公式、W、L、h、分位、成本、块长、经济阈值全部在看数前固定于本文件。
- 只承认一个预先指定主配置；稳健性格子只用于「会不会翻号」，不用于选最优。
- 不报告 in-sample 优化的「年化」。只报告 test、扣足成本、带 CI 的净 bps/笔，并由交易频率给一个明确标注为「情景而非承诺」的保守年化。
- 任何参数偏离必须另开假设、用未使用数据段检验，不回填本轮结论。
