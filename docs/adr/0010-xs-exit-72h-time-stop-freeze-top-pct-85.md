## 决策

1. **xs 臂退出冻结为：仅 72h 时间止损（次根 open 入场，持有 72 根 1h 后该根 close 平仓），不设任何紧价格止损。** 借用 5m scalp 的 1.5% 硬止损被本数据否决。
2. **top_pct 定格 85，关闭 M1 的 90 验证分支。** 在生产实际交易的 panic-gated 子集内，85-only 带（被 90 砍掉的那批）本身 +295.4bp / t=2.26 / CI 全正，与 90 子集同质；收紧到 90 平白损失 40% 样本与一半独立日，不提升门内 edge。
3. **不引入价格止损来做灾难保护。** 若未来需要尾部保护，必须另设一个**远宽的组合级**止损（如 ext 继续恶化或币级 −15~−20%），并独立走 ADR；不得复用 1.5%。
4. 本 ADR **只冻结研究/影子臂口径**，不构成 LIVE 授权。xs promote 仍受独立恐慌事件闸门约束（见"验收"）。

## 考虑过的备选

1. **1.5% 硬止损 + 72h（原 S3 假设）** —— 否决。深跌反弹单 76.5% 会先下探 1.5% 再收回，硬止损在底部洗出，WR 68.4%→23.5%、均值 296.8→52.8bp、CI 含零，摧毁均值回归 edge。
2. **更紧（1.0%）或更宽（2.0%/3.0%）价格止损** —— 否决。越紧越差（1.0% 仅 +20.6bp/85% 触发）；放宽到 3.0% 仍只 +133.3bp / t=1.68 / CI 含负，无一达到 t≥2 且 CI 下界>0。
3. **H48 / H96 时间止损** —— 否决。同止损网格下 H48/H96 全面弱于 H72（CI 均含零），72h 与 3.4 年数据上的超跌修复节奏匹配。
4. **top_pct 收紧到 90** —— 在 gated 口径下否决：85-only 带 +295.4bp/t2.26/CI 全正，是同质好信号而非杂质，90 仅减样本不增 edge。
   - 注：在**无波动门的全候选集**上，85-only 带确实弱（+51.7bp/t0.78/CI 含零）。这反向印证真正提供选择性的是 **panic gate（ATR 分位）**而非更极端的 ext 尾部门；故正确动作是保留 85 + 依赖 panic gate，不是改 top_pct。
5. **立即把 xs promote 到 enforce** —— 否决。跨源去相关后 HL 生产场所仅 3 个独立全市场恐慌事件（n=3 无推断力，naive 笔数 −1.8bp 是横截面相关假象），证据未达 promote 闸门。

## 影响 / 后果

- 对资金安全、生产交易路径、SHADOW 纪律：**当前零资金影响**。xs 臂 `mode=shadow`、panic gate record-only 默认关、`executed fills=0`；本 ADR 冻结的是研究/影子臂的退出与选择口径。明确"72h 时间止损、无紧价格止损"意味着未来 promote 到 LIVE 时，该臂**不依赖价格止损兜底**，尾部保护必须由组合级远宽止损 + 仓位/notional 上限承担（ADR-0001 不变量），这是 promote 前必须补齐的风控项。
- 需要的门禁 / CI / 启动断言：
  - 退出与 top_pct 口径以纯函数/研究脚本固化，promote PR 需附本 ADR 编号并由 `xs_exit_param_freeze.py`、`xs_top_pct_dual_count.py` 重算对账（gated close-only 应复现 ~+297bp / t≈2.83；85-only 带 CI 下界>0）。
  - promote 硬闸门（与单位/量级无关，不随本次 bp 修正改变）：HL 门内**去相关独立恐慌事件（gap3d）≥10 个**、事件级 t≥2、CI 下界>0；当前 n=3。
  - 部署后只读取证维持 `scripts/postdeploy_shadow_checks.py`（panic 字段 + maker 守卫）。
- 回滚方式：本 ADR 不改实时代码/配置，回滚即关闭本 ADR（标记 Deprecated 并说明新证据）；生产 `xs_reversal.top_pct` 维持 85 本就无需改值。若未来采纳价格止损或改 90，须新开 ADR 并链接本 ADR 为 Superseded。

## 验收

- 退出冻结（已满足，可复算）：gated n=98/79 日，close-only 72h = +296.8bp / WR68.4% / t2.83 / CI[+65.3,+374.8]；所有价格止损变体 t<2 且 CI 含零；`b54f7c0` 后单位为真 bp（脚本返回分数 net，×1e4）。
- top_pct 定格（已满足，可复算）：同一去重叠流上 gated 85-only 反事实带 +295.4bp / t2.26 / CI[+48.9,+517.2] 为正，90 子集相对 85 全集无净增益。
- promote 再评估触发条件（未满足，故维持 shadow）：HL 独立恐慌事件随时间累积到 ≥10 且事件级 t≥2、CI 下界>0；或出现证明"72h 无价格止损"在 LIVE 影子层尾部失控的反例。满足前不得 enforce。
