# 回测数字标注规范（F-2）

> 确立：2026-09-20（W4 / F-2）。权威全文为统一改造文档附录 D：
> `docs/research/2026-09/hermes-trader_统一技术改造文档_2026-09-19.md` §附录 D「本文档的自我约束」。
> 本文件是可长期引用的稳定入口（研究目录按月归档，链接会变）。

任何写入 SCOREBOARD / ADR / 提交说明 / 报告的回测数字，**必须**在同处标注三要素，缺一不可：

1. **配置源**：例如 `/data/.agent-config.json`（容器生产配置，权威）+ 取数日期/锚点 end_ms；
   禁止只写「线上配置」而不给来源。
2. **币池**：明确币数与名单口径（如 `bt_ready_pool` 81 币；旧 8 majors 口径须显式标注）。
3. **maxc（并发上限）**：例如 `maxc=2`（生产口径）或「无约束（峰值并发 N）」。

配套要求（摘自附录 D，遇冲突以附录 D 为准）：

- 分解项先溯源语义再用，不把标签差异当机制差异；
- 显著性只用按天块自助（block bootstrap），不用单笔 t 检验；
- 对比实盘出场用 `filt` / `filt_exch`（B-3 已证这两臂出场占比对齐实盘），
  `filt_ra` 已被否证（max_loss 72.3%，反向偏离）；
- 持仓时长对比用 `hold_bars == 1` 口径，不直接用分钟数；
- 报告冲突按统一文档 §0.2 权威性排序取信（P6b > P6b1c > P5-1 > P3-4 > …）。
